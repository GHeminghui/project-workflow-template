# 项目文档索引

本目录存放跨阶段的文档与决策记录。

## 目录说明

- `README.md`：本文件，项目文档导航
- `adr/`：架构决策记录（Architecture Decision Record）

## 相关文件

- `../PROJECT_STATE.json`：项目状态（唯一数据源）
- `../AGENTS.md`：工作流规范（每次会话自动加载）
- `../.trae/`：TRAE 配置（hooks、commands、scripts）
