# 阶段 2：设计（Design）

## 目标
把需求转化为可执行方案，包含产品设计与技术设计。

## 准入条件
- 调研阶段已完成并通过 `/advance` 推进
- 已明确需求清单与约束条件

## 推荐能力
- `brainstorming`：澄清需求与设计方向
- `Praxis:design`：标准/复杂需求的设计流程
- `whiteboard`：架构图、流程图、ER 图、时序图
- `visualize-code`：分析已有代码生成架构图（改造类项目）
- `Frontend Design` / `web-app-development`：UI/UX 设计

## 准出产物
- [ ] `product-spec.md`：功能列表、交互、验收标准
- [ ] `tech-design.md`：架构、数据模型、接口、选型理由
- [ ] `architecture.html`：架构图/流程图（whiteboard 导出）

## 交付给下一阶段
可拆分为任务的设计方案 + 验收标准。

## 完成标准
`PROJECT_STATE.json` 中 `design` 阶段的 checklist 全部勾选后，运行 `/advance`。
